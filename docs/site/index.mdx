## What is a PEP?

*PEP*, or *Portable Encapsulated Projects*, is a **community effort to make sample metadata reusable**. PEPs decouple metadata from analysis by providing:

1. a standardized metadata structure;
2. a metadata validation framework; and
3. programmatic metadata modifiers.

A PEP is written using a familiar **yaml + csv** format that can be read by our R and Python packages, and well as by workflow frameworks.
PEP is your metadata solution for sample-intensive research projects.
The PEPkit suite is a set of modular tools that work to help you use PEP in practical applications.
